# 1.0.8.7

- 版本号更新至 1.0.8.7（versionCode 87）。
- 设置页移除多余的「通行密钥登录」入口，通行密钥仍在登录页使用。
- 应用底部与相关文案统一显示为「北化课表」。
- 「在线同步」默认开启；仍可在设置中手动关闭。
- 密码登录且已保存密码时，手动更新课表或下拉刷新若遇到教务 Cookie 失效，会自动静默续期并继续刷新。
- 修复考试周次按日期错位的问题：同一周的周一、周二等日期现在显示相同的教学周。
- 课表周视图顶部增加月份提示，跨月周会在日期前标注月份（如 11/1），左侧同时显示 10月/11月。
- 课表桌面小组件同步增加月份：星期表头显示 `月/日`，底部显示当前周所属月份，切换周时日期与月份一起更新。
