## [1.0.9.13] - 2026-11-17

- 感谢各位同学对北化课表 App 的喜欢，也感谢各位同学提出的宝贵建议，大家有问题和想法随时跟我说哦
- 新增「好友」：用一串短号（BH-XXXXXX）互相添加，不用交换学号密码，加完就能聊天
- 支持互传课表：把课表发给好友，对方收到后自动存在本机，不用手动挑文件
- 课表页「切换课表账号」新增「朋友的课表」分区，点一下就能看对方这学期上什么课，切回自己的也是一下
- 桌面课表小组件支持显示朋友的课表：每个小组件单独设置，标题和内容都跟着变；对方课表删掉后自动回到自己的
- 设置新增「桌面小组件」管理页：能看到桌面上摆了哪几个，逐个改名称、换账号或换成朋友的课表
- 底部导航调整：「课程」和「抢课」合并成二级目录，腾出的位置给「好友」
- 课表页顶栏统一：账号切换芯片改用和「今天 / 本周」「日 / 周」同一套玻璃材质，并挪到学期那一行，窄屏上设置按钮不会再被挤出屏幕
- 好友聊天记录会存在本机，进会话秒开；拉取只取新消息，作者服务器压力小一点
- 设置 →「意见反馈」可以直接给我留言，我的回复会出现在同一个页面里

## [1.0.9.12] - 2026-10-26

- 感谢各位同学对北化课表 App 的喜欢，也感谢各位同学提出的宝贵建议，大家有问题和想法随时跟我说哦
- 新增全局字体大小设置：无级滑杆 + 五档吸附 + 百分比输入框，只影响 App 显示
- 课表设置新增格子高度：32–112dp 七档、滑杆与输入框，一屏可显示更多节次
- 新增自建考试：四六级 / 计算机等级 / 教资 / 数学竞赛 / 考研等模板，可多选提醒并一键加入系统日历
- 设置新增底部导航：可调整标签顺序、隐藏不用的页面
- 修复系统大字号下星期行日期被裁掉一半的问题
- 修复隐藏底部标签时闪退的问题，并修复长考试名称被标签挤成省略号
- 考试类型标签统一为「期末 / 期中 / 补考」等短标签，不再显示冗长的括号说明
- 总体课程明细改为「已出分优先」排序：先按学期从新到旧，同分数高的在前，未出分统一沉底
- 总体成绩的分项详情不再被刷新冲掉（按课程代码保留，并接入与学期页一致的逐课分项通道）
- 课表设置新增「显示非本周课程」：非本周的课灰色置底并标注，同一时段多门课时优先显示本周要上的，点卡片可按时间查看该时段全部课程
- 修复考试页切换「全部」学期时闪退的问题（改为循环所有学期合并拉取）
- 修复同一门课期中、期末两场考试在列表里被合并/串数据的问题
- 学期末（第 18 周及以后）的考试标签自动按时间纠正为期末
- 新增课表小组件字体大小设置（无级滑杆 + 五档吸附 + 百分比输入框）
