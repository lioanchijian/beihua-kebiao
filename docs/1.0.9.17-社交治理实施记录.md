## 服务端改动

文件：`server/usage-stats/server.py`

### 数据表

- `friends.remark`：好友备注，按 `owner → friend` 维度保存，只影响设置者自己看到的名字。
- `fb_users.admin_note`：管理员给反馈用户的后台备注，App 端不返回、不展示。
- `friend_blocks(owner, blocked, created_at)`：拉黑关系，独立于好友关系，便于解除。
- `friend_reports(id, reporter, target, message_id, reason, detail, status, created_at)`：举报记录。
- `friend_lookup_log(owner, created_at)`：短号预览限频日志，保留一天。
- `server_config(key, value)`：当前存 `social_enabled` 总开关。

启动时 `init()` 会自动 `ALTER TABLE` 补 `remark` / `admin_note`，并用 `CREATE TABLE IF NOT EXISTS` 创建其余表，不需要手工迁移。

### 新增接口

| 方法 | 路径 | 说明 |
|---|---|---|
| POST | `/api/friend/remark` | 设置/清除好友备注，最多 12 字 |
| POST | `/api/friend/report` | 举报用户，可带 `messageId`、原因、补充说明 |
| POST | `/api/friend/block` | 拉黑并删除好友，双方都不能再发消息或重新添加 |
| POST | `/api/friend/unblock` | 解除自己设置的拉黑 |
| GET | `/api/friend/blocked` | 我的黑名单 |
| GET | `/api/friend/lookup` | 精确短号预览，不创建申请 |
| GET | `/api/friend/status` | 好友功能总开关状态 |
| GET | `/api/friend/admin/reports` | 后台举报列表 |
| POST | `/api/friend/admin/report-action` | 处理举报：封禁目标或标记已处理 |
| GET/POST | `/api/friend/admin/config` | 读取/切换好友功能总开关 |
| POST | `/api/feedback/admin/note` | 给反馈用户写后台备注 |
| POST | `/api/feedback/admin/ban` | 封禁/解封反馈用户 |

### 限流与防滥用

- 消息：仍保留原有 2 秒发送间隔；新增每账号 20 条/分钟、200 条/天，超限返回 429。
- 短号预览：每账号 20 次/分钟；仅支持完整短号精确查询，目标被举报封禁或不存在时统一返回“没找到”。
- 举报/拉黑/备注不占用消息额度。
- 好友接口统一检查 `fb_users.banned`；被封禁账号不能添加、发送或预览。
- 总开关关闭后，历史会话仍可读，但添加、预览、发送等写操作返回 403。
