# 1.0.9.18 上游域名依赖清理记录

日期：2026-11-19

## 目标

移除上游作者留下的第三方服务域名及其客户端依赖，同时不影响当前可用功能。

## 已删除

### 学校适配

- `network/SchoolServiceEndpoints.kt`
- `network/SchoolSuggestionApi.kt`
- `network/SchoolAdaptationManager.kt`
- `ui/screen/SchoolAdaptationScreen.kt`
- `ui/screen/SchoolAdaptationHistoryScreen.kt`
- 测试 `network/SchoolAdaptationManagerTest.kt`
- `LoginScreen` 的 `onSchoolAdaptation` 参数
- `LoginActivity` 的 `showSchoolAdaptation` 状态与 `SchoolAdaptationFlow` 分支
- `LoginActivity` / `MainActivity` 的 `SchoolAdaptationCompletionReminder`
- `SettingsRoute` 中的未使用 import

说明：原有 UI 入口本来没有接到 `onSchoolAdaptation`，正常用户无法进入提交页；删除后当前界面不变。唯一的行为变化是：以前提交过适配申请的用户，不再看到第三方返回的“适配已完成”提醒。

### 匿名统计

- `usage/` 整包（`HttpUsageTransport`、`UsageReporter`、`UsageStatsManager`）
- `ui/screen/UsageNotice.kt`
- 测试 `usage/` 下两个单测和两个设备测试
- `UserManager` 中两处 `refreshEligibility()` 调用

说明：该统计通道原本 `initialize()` 从未调用，实际不会发请求。自有 `buctkb.cn/api/stats/ping` 匿名统计保留，不影响。

### 旧反馈通道

- `network/FeedbackManager.kt`
- `ui/screen/FeedbackHistoryScreen.kt`

说明：旧反馈历史页没有入口。当前在用的 `FeedbackApi` / `FeedbackScreen` 走自有 `buctkb.cn`，保留。

### 问卷模块

- `survey/` 整包
- `ui/screen/SurveyCenterScreen.kt`
- `ui/screen/SurveyReminder.kt`
- `ui/route/SurveyRoute.kt`
- `SurveyWebViewActivity.kt`
- Manifest 中的 `SurveyWebViewActivity` 注册
- 问卷相关单测与设备测试

说明：问卷中心/提醒没有实际入口，删除不影响当前 UI。

### 未使用的上游统计后端

- `sources/android-app/usage-stats-service/`

## 保留的现有功能

- 登录：账号密码、验证码、短信、统一认证、研究生 GMIS、学校下拉与自定义学校
- 课表、成绩、考试、抢课、定时任务、桌面小组件
- 好友、聊天、备注、举报/拉黑、短号
- 自有匿名统计 `buctkb.cn/api/stats/ping`
- 自有匿名反馈 `buctkb.cn/api/feedback/*`
