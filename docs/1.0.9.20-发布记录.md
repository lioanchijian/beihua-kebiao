## 5. 回滚

服务器回滚：

```bash
cd /root/beihua-deploy
tar -xzf beihua-site-backup-20261123-0030.tar.gz -C /
# 或只恢复站点
tar -xzf beihua-site-backup-20261123-0030.tar.gz -C /var/www beihua
nginx -t && systemctl reload nginx
```

回滚后 `version.json` 会回到 1.0.9.18，但 1.0.9.19/1.0.9.20 的包和清单仍保留在备份目录，可单独恢复。

## 6. 注意

- 不要覆盖 `version.json`：它必须长期固定 1.0.9.19，否则 1.0.9.18 及更早的旧更新器会拒绝 1.0.9.20 的新签名。
- 不要删 `legacy-debug.keystore` 和 `lineage.bin`。
- 后续发新版时只更新 `/var/www/beihua/version-latest.json`，不要动 `version.json`。
