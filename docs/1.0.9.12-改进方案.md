## 二、需求一：字体大小设置 + 显示裁切修复

### 2.1 先说那个「1234567 显示只有一半」

从同学截图看是**桌面小组件**，不是 App 内部。可能的原因有两处，需要先复现确认：

- **A. 表头被挤压**：`widget_schedule.xml` 的星期表头是 `wrap_content`，文字是两行（`一\n10/26`，10sp）。当组件被放到很矮（2×2 或更小）时，根布局 `match_parent` 下 `ListView` 用 `0dp + weight=1` 抢占剩余空间，表头可能被裁掉下半截。
- **B. 行高不足**：`widget_schedule_row.xml` 里课程行撑不满时文字截断。

**做法**：我在你手机上用 adb 把组件拉到最小尺寸复现，定位到具体是哪一个，再针对性修：
- 表头改成固定最小高度 + `maxLines=1` + 日期单独一行可隐藏（窄组件只显示「一」不显示日期）
- 组件整体加 `minHeight` 声明，并在 `onAppWidgetOptionsChanged` 里按尺寸切换「紧凑/标准」两套布局

> 这一步不改代码逻辑，先出诊断结论给你看，避免瞎猜。

### 2.2 字体大小设置页

**入口**：设置 → 外观 → 「字体大小」（新页面，和现有的「壁纸」「启动页」并列）

**界面**（沿用现有玻璃风格，`InsetGroupedSection` + `SystemSegmentedControl`）：

```
┌─────────────────────────────┐
│  ← 字体大小                  │
│                             │
│  ┌───────────────────────┐  │
│  │  第 9 周               │  │  ← 实时预览卡片
│  │  高等数学 A             │  │     用真实课表卡片渲染
│  │  教101 · 张老师         │  │
│  └───────────────────────┘  │
│                             │
│   小 ──────●────── 大        │  ← 滑杆，5 档吸附
│                             │
│   标准（100%）               │
│                             │
│  说明：只影响本应用，不影响系统 │
└─────────────────────────────┘
```

**技术方案**（关键点，决定会不会"越改越乱"）：
- 新建 `FontScaleManager`，值域 `0.85 / 1.0 / 1.15 / 1.30` 五档吸附（0.85/0.925/1.0/1.15/1.30），存 SharedPreferences。
- 在 `MainActivity` 根部用 `CompositionLocalProvider(LocalDensity provides density.copy(fontScale = base * scale))` 覆盖。
  → 所有 `sp` 自动跟着缩放，**不用逐个改字号**，也不会影响系统和其他 App。
- 例外：图标尺寸、间距用 `dp`，不受影响，所以布局不会整体肿大。
- 小组件（RemoteViews）**不受此设置影响**，它有自己的字号，单独在组件配置里调（见 2.1）。

**边界处理（你说的"边框设置好"）**：
- 所有含文字的行，`height` 固定值改为 `heightIn(min = ...)`，让行高随字号长大；
- 课程卡片文字 `maxLines` + `TextOverflow.Ellipsis`，放大后最多 2 行，不撑破格子；
- 分组卡片的分隔线用 `Modifier.drawBehind` 跟随内容高度，不写死；
- 输入框、按钮的内边距按 `dp` 不变，文字变大后自动居中，不压边；
- 1.30 档下逐页回归：登录页、课表、成绩、设置、所有弹窗。

### 2.3 需要你定
- 字号是**全局**（整个 App）还是**只课表/成绩**？我建议全局，一致性最好。
- 5 档够不够？要不要做成无级滑杆？我建议 5 档吸附，避免用户调到卡片的临界值。

## 三、需求二：格子高度设置

**入口**：课表设置（`ScheduleSettingsScreen`）→ 基础设置 → 「格子高度」，放在「每天节数」下面。

**交互**：
- 复用现有滚轮弹窗（`showPeriodCountPicker` 那套），列出 `64 / 72 / 80 / 88 / 96 / 104 / 112 dp` 七档；
- 每档标注「紧凑 / 标准 / 宽松」；
- 选完即时生效，课表页无需重启；
- 底部一行「恢复默认（84dp）」；
- 默认值跟随屏幕：高屏 84、矮屏 68（保持现有行为不变）。

**实现**：
- `ScheduleSettingsManager` 新增 `KEY_PERIOD_HEIGHT`，按账号隔离（和 `periodCount` 同一套 `scopedKey`）；
- `schedulePeriodHeight()` 改为读设置，兜底原值；
- `rememberCoursePeriodHeight()` 保持"内容多时自动撑高"的逻辑，用户设置的是**基准高度**而不是硬上限。

**风险**：调到 112dp 时一屏只能看 5 节，用户可能觉得"课表变难用了"。所以上限收在 112，并在选择器里给一句提示。

## 四、需求三：自主添加考试

这是三项里工作量最大的，但价值也最高（四六级、教资、竞赛这些教务系统里根本没有）。

### 4.1 数据结构

```kotlin
data class CustomExam(
    val id: String,              // UUID
    val title: String,           // 显示名，如「CET-4 四级」
    val course: String = "",     // 关联课程，可空
    val startAt: Long,           // 毫秒时间戳
    val endAt: Long = 0L,        // 0 表示只记开始
    val location: String = "",
    val seat: String = "",
    val note: String = "",
    val tag: String = "自建",     // 自建 / 模板名
    val remindOffsets: List<Int> = listOf(1440, 120), // 提前分钟：1天、2小时
    val hidden: Boolean = false, // 已考完可隐藏
    val semester: String = "",   // 归属学期，空=当前
    val calendarEventId: Long = 0L // 写入系统日历后回填，防重复
)
```

存储：沿用 `ScheduleSettingsManager` 的按账号 `SharedPreferences`（JSON 数组），与自定义课程一致。**不上传服务器**，换设备需重新添加（和现在自定义课程的行为一致）。

### 4.2 与教务考试合并展示

- `ExamScheduleSharedCache` 拆成两层：`remoteExams`（教务）+ `localExams`（自建）
- 列表页合并排序，自建项右侧打「自建」小标签
- 课表日视图 / 周视图的考试卡片同样合并，自建考试用虚线描边区分
- 去重：同标题 + 开始时间相差 <5 分钟 → 提示"疑似重复"

### 4.3 模板

不硬编码具体年月日（每年都变，写死必过期），而是存**相对规则**，生成时按当年算：

| 模板 | 规则 | 生成后 |
|---|---|---|
| 大学英语四六级 | 6 月 / 12 月第 2 个周六，09:00-11:20 | 可改日期、考场 |
| 全国计算机等级考试 | 3 月 / 9 月最后一个周末 | 可改，标注"分批上机" |
| 教师资格证（笔试） | 3 月 / 9 月中旬周六 | 可改 |
| 全国大学生数学竞赛 | 11 月第 2 个周六 09:00-11:30 | 可改 |
| 考研初试 | 12 月倒数第 2 个周末 | 可改 |
| 普通话水平测试 | 无固定日期 | 只填名称，强制手选日期 |

选中模板后进入编辑页，**所有字段都可改**，模板只是省去打字。

### 4.4 提醒

直接复用 `ScheduleReminderScheduler` 那套 AlarmManager 机制，新增 `ExamReminderScheduler`：

- 可选提醒点：提前 1 天 / 2 小时 / 30 分钟 / 自定义（多选）
- 通知标题：「明天 09:00 CET-4，教 101」
- 点击通知 → 跳到考试详情
- 权限态复用现有 `ReminderPermissions` 判断（通知 / 精确闹钟），被拒时在设置页给红点提示
- 考完自动失效，不会残留闹钟

### 4.5 创建日程（系统日历）

两条路，优先第一条：

1. **直接写入**：`CalendarContract.Events` 插入，需要新增 `READ_CALENDAR` / `WRITE_CALENDAR` 运行时权限；写入后把 `eventId` 存回 `CustomExam`，删除/修改考试时同步更新，不重复创建。
2. **降级打开系统日历**：`Intent(Intent.ACTION_INSERT).setData(Events.CONTENT_URI)` 预填标题/时间/地点，用户点保存。**不需要权限**，兼容性最好。

我的建议：默认走 2（零权限摩擦），在设置里给一个「自动写入系统日历」的开关，开了才申请权限走 1。

### 4.6 入口

- 成绩页 → 考试 Tab → 右上角 `+`
- 课表日视图：当天没有考试时，底部一行「+ 添加考试」
- 设置 → 考试提醒（总开关 + 默认提醒时间）
